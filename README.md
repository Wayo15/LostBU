# LostBU — Campus Lost & Found

A web application for reporting and searching lost and found items on campus.

## Project structure

- `FE/` — Frontend (HTML, CSS, Vanilla JavaScript, Vite)
- `BE/` — Backend (Node.js + Express REST API, SQLite)
- `docs/API_CONTRACT.md` — shared API contract and data model

## Status

Work in progress. Setup and usage instructions will be completed as features are finished.
